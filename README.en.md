# PlushOps

PlushOps is a native Android app for personal management of claw machines. The project is currently in development.

## Current scope

The app currently includes the initial project structure, a home screen, Machines and Visits screens with empty states, and basic navigation between them.

## Technologies

- Java
- XML layouts
- Android Studio and Android SDK

## Run locally

1. Clone the repository.
2. Open the project in Android Studio.
3. Wait for Gradle to finish syncing.
4. Run the `app` configuration on an Android device or emulator.
