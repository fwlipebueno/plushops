# PlushOps

PlushOps é um aplicativo Android nativo para o gerenciamento pessoal de máquinas de pelúcia. O projeto está em desenvolvimento.

## Escopo atual

O aplicativo conta atualmente com a estrutura inicial, uma tela principal, telas de Máquinas e Visitas com estados vazios e navegação básica entre elas.

## Tecnologias

- Java
- Interfaces em XML
- Android Studio e Android SDK

## Execução local

1. Clone o repositório.
2. Abra o projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute a configuração `app` em um dispositivo Android ou emulador.
